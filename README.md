# BSLamp — разработка и доработка 1С

Сайт студии [bslamp.ru](https://bslamp.ru): Vite + Three.js + GSAP, 3D-склад с пролётом камеры.

```bash
npm install
npm run dev     # разработка
npm run build   # сборка в dist/
```

Публикация — GitHub Pages из ветки `gh-pages` (собранный `dist/`): `npm run deploy`.
Тексты, цены и контакты — в `src/content.js`. 3D-модели — Sketchfab, CC BY 4.0 (авторы указаны на сайте).
